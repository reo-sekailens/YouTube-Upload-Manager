## Status

`completed`

## Outcome

The repository root uses the canonical GNU Affero General Public License v3.0
text. GitHub can detect and present it as AGPL in the repository sidebar.

## Acceptance criteria

- Keep the license in the root `LICENSE` file.
- Use the unmodified canonical AGPL v3.0 license text so GitHub recognizes it.
- Retain the project copyright and AGPL-or-later intent through a concise
  README notice.

## Evidence

- `LICENSE` was replaced from the official GitHub license template for
  `agpl-3.0`.
- The README license badge and license section link to the root file.
