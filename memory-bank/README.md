# Memory Bank

This folder is the durable operating context for people and AI agents working in this repository. Read it before making non-trivial changes and update it when a decision, boundary, or delivery state changes.

## Reading order

1. [Project brief](project-brief.md) — product purpose and outcomes.
2. [Architecture](architecture.md) — system boundaries and intended design.
3. [Technical notes](technical-notes.md) — conventions, safety constraints, and unknowns.
4. [Progress](progress.md) — current verified state and next milestone.
5. [Task index](tasks/_index.md) — the source of truth for scoped work.

## Maintenance rules

- Record facts that are verified in the repository or an authoritative service; label assumptions and decisions separately.
- Do not store credentials, OAuth tokens, personal data, unredacted video metadata, or private channel details here.
- Keep this concise. Link to source files, issues, or runbooks instead of copying implementation details.
- Update the relevant page in the same change as a material architectural, workflow, or delivery decision.
